# Award Day に向けた進捗（2026-11-08）

本番は **11月15日（日）**。最優先は Bluesky 賞、あわせて Best Hack Award を目指す。「何気ない投稿を組み合わせると何が分かるか」と「投稿を見直すと推定がどう変わるか」を、実際に動くデモと数字で伝える。本番環境は AWS とし、RunPod は使わない。

## チーム共有用の要約

「みーつけた」は、本人の Bluesky 投稿を取得し、写真・本文の手がかりから根拠つきで推定し、投稿の仮除外・確認後の削除・再診断まで実装済みです。Hack Day の実投稿デモでは、12投稿から18の手がかりを抽出して推定結果を表示しました。アプリのセキュリティ検査は12カテゴリで実施し、見つかったモデル送信先と投稿 URI の検証の弱点は修正済みです。

AWS への Terraform apply は完了し、GPU 上の vLLM は `/health` が 200、キーなしの `/v1/models` が 401 を返すところまで確認しました。GPU はモデル取得後に停止済みです。一方、**CloudFront からのログイン・診断・仮除外・削除の通し動作は未確認**です。今週は本番経路の完成、実測評価、発表用デモの順に進めます。

## 確認済みと残り

| 領域 | 11/8 時点 | 次に確かめること |

| 評価・発表 | README に実投稿デモの記録あり | 約3種類の架空のデモ用アカウントで正解・不正解・診断時間・仮除外前後を計測し、スライド・ポスター・予備動画に反映する |

AWS には Budgets の通知（$50 を含む）・$80 での GPU 停止アクション、公開時間の起動停止、WAF、最小権限の停止担当ユーザーを Terraform で設定した。11/15 の公開予定は 11:00〜16:20、GPU は 10:15 起動・16:30 停止。**設定があることと、公開経路や停止動作を実地で確かめたことは別**として扱う。GPU を止めても、ほかの AWS リソースの費用は続く。

## 11/15 までの進め方

1. **11/8〜10：動く本番経路と安全性を固める。** 担当を決め、アプリ EC2 を起動して CloudFront から一連の操作を確認する。ログインは取り消せる App Password を案内し、本パスワードを避ける運用を決める。消してよいデモ投稿1件で削除を確認する。OCR が間に合うかも判断する。
2. **11/9〜12：効果を測る。** 約3種類の架空のデモ用アカウントで、推定の正解・不正解、診断時間、仮除外前後の項目数を同じ方法で記録する。11/11 にデモと発表初稿、11/12 に外部の試用と予備動画を終える。
3. **11/13〜15：発表を仕上げる。** 11/13 に機能を凍結し、README・スライド・EXPO ポスターを完成。11/14 に通し練習と質疑応答を行い、11/15 は「問題提起 → 推論 → 根拠 → 仮除外 → 変化」を短く見せる。

投稿前のリスク検知は、上の必須項目が安定した後に工数で判断する。新しい SNS、推論ルールの大量追加、本番直前の大規模変更は今回の対象にしない。
