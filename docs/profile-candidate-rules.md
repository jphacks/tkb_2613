# 29項目プロフィール候補の証拠ルール

この表の29項目は `ProfileAttribute` から `home_room` を除いたもの。表は「候補を画面に出す最低条件」であり、人物同定や真実の確認ではない。単独の手がかり、画像上の近接、投稿頻度、沈黙から本人との関係を補わない。実装済みの決定的ルールおよび統合された `RulesR`（R1〜R12）・`RulesX`（X1〜X5）の結合ルールだけが候補を返す。未実装の条件は `unknown` とする。

候補セットの状態は `candidate`（表示する値が1つ）、`ambiguous`（同等の根拠を持つ値が2〜3個）、`unknown`（根拠不足または棄却条件に該当）、`conflict`（独立した検証器が明示的な両立不能を示した場合）である。現在の推論ルールは両立不能を確定する検証器を持たないため、`conflict` は生成せず、否定・第三者・訪問などの文脈は候補を棄却して `unknown` にする。否定に一致する値の観測根拠は `conflicting_evidence` に保持する。候補値は診断時点で投稿に明示・観測された具体値を表す。候補が1つでも他の値が存在しないことを意味しない。

`candidate_pool` は証拠条件を満たした異なる値を全て保持し、`rank` は provisional score 降順、正規化値の昇順で1から付ける。`confidence` は校正済み確率ではなく順位付け用の暫定スコアである。`candidates` は表示用で、最上位が `weak` なら同じく `weak` の上位最大3件をスコア差に関係なく表示する。最上位が `found` なら同じ grade かつ最上位との差が0.15以内の上位最大3件を表示する。0.15は候補同士の近さを決める相対差であり、確度の下限ではない。表示候補を作る前に、候補生成ルールの必須根拠と観測別品質条件を満たす必要がある。`found` / `weak` はスコア閾値ではなく、根拠が主張の種類を直接特定するか、複数の観測を組み合わせるかを示す証拠グレードである。`ProfileEvidencePath.provenance` は各完全経路を `direct_disclosure`（値の直接開示）、`combined_inference`（複数根拠から値を導出）、`unclassified`（移行前データ等で未分類）に分類する。同じ候補値に両方の経路があってよい。未分類を推論として扱わない。`counter_evidence` は候補を否定する明示的な投稿根拠、`conflicting_evidence` は値を出せない属性で見つかった明示的否定の根拠を保持する。仮除外・削除比較では表示枠の外も含む `candidate_pool` を再評価し、候補の繰り上がりを計算する。削除提案は、値順位の変更を属性が崩れた件数に含めず、候補が一つも残らない属性数、失われる値の数、投稿数の少なさ、診断順の順に評価する。

`found` は指定した限定ルール上で主張の種類と候補値が直接開示・観測されている証拠グレードであり、候補が現実に正しいという意味ではない。例えば、本文に明示された本人の勤務先名を独立した型付き観測で一致確認した候補は `found`、居住エリアを自宅関係の手がかりと別投稿の地名から結ぶ候補は `weak` とする。画面ではどちらも候補として表示する。

値の重複判定と順位の正規化は Python・TypeScript・評価スクリプトで共通して NFKC + Unicode `lower` + trim を使う。`casefold` は使わないため、`Straße` と `STRASSE` は別候補である。

## 実装範囲

既存の横断ルールは `residential_area`, `regular_station`, `regular_line`（直接開示と限定的な駅間組合せ推定）, `employer_name`, `school`, `child_age` に加え、RulesR（R1〜R12）・RulesX（X1〜X5）・搭乗券の BP1/BP2 の結合経路を29項目へ統合済み（BP1 は `full_name` と `announced_long_absence`、BP2 は `announced_long_absence`）。直接の本人申告と一致する型付き観測は、明示語と値が同一投稿内で一致する場合だけ追加候補にする。`realtime_location` と `actual_home_absence` は鮮度を満たす場合だけ候補にする。`facial_appearance` は本人の自己言及と同一投稿の顔検出がある場合も、自己申告文の存在のみを示す候補とし、本人判定・特徴推定をしない。`home_room` はこの29項目の出力対象外。

規則の confidence は暫定スコアで、校正済み確率ではない。弱い最上位にはスコア差を使わず、証拠条件を満たす弱い候補を最大3件表示する。強い最上位には同じ evidence grade のうち最上位との差0.15以内を最大3件表示する。値が1つの場合も確定事実とは表現しない。
