## 所見

- `_validation_error`（[api/src/tkb_api/main.py](../../api/src/tkb_api/main.py)）が、FastAPI既定の「送信値をそのまま返す」挙動を上書きし、`loc`/`msg`/`type` だけに整形。パスワードなどの入力値は応答に出ない。
- ログイン失敗は、ハンドル違いもパスワード違いも同じ `LoginFailedError` → 401「ハンドル名かパスワードが違います」。TestClient でログイン依存を各例外に差し替え、存在/非存在handle で応答（ステータス・本文）が同一になることを実測。アカウントの存在を区別しない。
- 500（内部例外）は TestClient で依存に例外を注入して誘発。本文は `Internal Server Error` のみで、例外メッセージ・スタックトレース・内部パスは出ない（`debug` 未設定のため）。
- `password` は `SecretStr`。repr・バリデーションエラー文言にも値が出ない。
- アプリログは件数・秒数だけを出す方針（`_configure_logging` のコメント）。モック診断実行後のログを `password|本文|DID|handle` で検索したが該当なし。
- 補足: `Server: uvicorn` ヘッダが出る（低リスクのバージョン告知程度）。気にするなら中継側で落とす。
