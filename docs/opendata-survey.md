## 2. データごとの詳細

### 2.1 T21 指定緊急避難場所・指定避難所（国土地理院）

- 案内: https://www.gsi.go.jp/bousaichiri/hinanbasho.html 、ダウンロード: https://hinanmap.gsi.go.jp/index.html
- 「同意する」ボタンは一覧ページへの移動だけで、トークンや Cookie は要らない。一覧ページの JavaScript も、固定 URL の CSV と GeoJSON を取ってブラウザ内で zip にしているだけ。
- 項目
  - 指定緊急避難場所: 共通ID、施設・場所名、住所、災害種別8列（洪水、崖崩れ・土石流・地滑り、高潮、地震、津波、大規模な火事、内水氾濫、火山現象。該当は「1」）、指定避難所との住所同一、緯度、経度、備考
  - 指定避難所: 共通ID、施設・場所名、住所、指定緊急避難場所との住所同一、その他市町村長が必要と認める事項、受入対象者（指定福祉避難所だけ）、緯度、経度、備考
- 市区町村コードの列はない。共通ID（14桁）の2〜6桁目が市区町村コード（例 `E1322800001201` → 13228 あきる野市）なので、そこから取れる見込み（全行で成り立つかは実装時に確かめる）。都県のファイルには県外の施設も入っている（例: 埼玉県のファイルに「※埼玉県熊谷市指定」の群馬県太田市の施設）ので、市区町村コードで絞る。
- 載っているのは「市町村が登録しかつ公開の同意を得たもの」だけ。1都3県の市区町村 212 のうち 4 は非公開。
- 出典の書き方: 「出典：国土地理院ウェブサイト（当該ページのURL）」。加工したときは「「指定緊急避難場所データ」（国土地理院）（当該ページのURL）をもとに作成」の形（https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html ）。
- **ご利用上の注意**: 「最新でない場合や未掲載の場合があるため、最新かつ詳細の状況などは必ず当該市町村にご確認ください」「本データを用いた情報を第三者に提供する場合は、上記1．～3．の注意事項が正確に伝わるよう、十分にご留意ください」。画面では位置の推定にだけ使い、避難情報としては見せないので、根拠の出典の横に「避難所の情報としては使わないでください」の注記を足すのが安全。

### 2.2 T22 法人番号 基本3情報 全件データ（国税庁）

- 項目（リソース定義書 4.0版、30列）: 法人番号、処理区分、商号又は名称、法人種別、国内所在地（都道府県・市区町村・丁目番地等）、都道府県コード、市区町村コード、郵便番号、登記記録の閉鎖等年月日、フリガナ、検索対象除外 など。
- フリガナは全件データに入っているが、登録のない法人は空。1都3県で約6割に入っている。
- 閉鎖した法人も入っている（処理区分 21、1都3県で 約31万件）。取り込むときは閉鎖済みを除く。
- 個人事業主は法人番号の指定対象外で、データにも入っていない。
- **取得の仕組み**: ページはフォームの POST（`event=download&selDlFileNo=番号`）で zip を返す。調査日には、ページ内のトークンなしでも POST だけで取れた。ただし、ファイル番号（2026-10-30 版の Shift_JIS CSV は埼玉 28374、千葉 28378、東京 28382・28383、神奈川 28395）は版ごとに変わるとみられ、`fetch.sh` で取るにはページの HTML から番号を抜く処理が要る。トークンの検査が将来有効になる可能性もある。e-Stat と同じく「ブラウザで取って `data-prep/raw/` に置く」扱いにするほうが壊れにくい。
- Web-API はアプリケーション ID が要り、発行に「２週間から１か月程度」かかる。今回は使わない。
- 出典の書き方: 「出典：国税庁法人番号公表サイト（国税庁）（当該ページのURL）」。加工したときは「国税庁法人番号公表サイト（国税庁）（当該ページのURL）を加工して作成」（https://www.houjin-bangou.nta.go.jp/riyokiyaku/index.html ）。
- **大きさの注意**: 1都3県で 約226万件。閉鎖を除いても 約194万件ある。本番のアプリは t3.small（2GB）で、api のプロセスに全件を読み込むとメモリが厳しい。engine に渡すのは「正規化した商号 → 法人番号・商号」だけにするか、法人種別（301〜305 の会社）に絞るなどの縮小が要る。

### 2.3 T23 バス停留所 P11（国土交通省）

- 項目: 点の座標、バス停名（P11_001）、バス事業者名（P11_002。コミュニティバスは自治体名）、バス系統（P11_003_01〜35）、バス区分（P11_004_01〜35）、備考。
- 上り・下りのバス停は原則1か所にまとめてある。デマンドバスと高速バスは入っていない。
- **タスク票の前提（非商用・2010年度前後）は古い版の話**。今の最新の令和4年度版はオープンデータで、非商用なのは平成22年度版だけ。古い版のページ（`KsjTmplt-P11.html`）は平成22年度版を説明しているので、取得元は `-v3_0` のページにする。
- 出典の書き方: 「「国土数値情報（バス停留所データ）」（国土交通省）（https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P11-v3_0.html ）を加工して作成」。根拠には時点（令和4年度）も出す。

### 2.4 T24 小学校区 A27・中学校区 A32（国土交通省）

- 項目: 学区の多角形、行政区域コード、設置主体、学校コード、学校名、所在地（A27_001〜005、A32_001〜005）。学校コードは文部科学省の学校コードなので、今の `schools.parquet` とつなげられる見込み（列の形式は実装時に確かめる）。
- 私立・国立・特別支援学校は入っていない。ページに「推定による直線的な境界線やポリゴンの重複」があり「公式な資料としては扱えない」と書かれている。
- 自治体ごとの利用条件（Excel の「R3小学校区 利用条件」列。中学校区もほぼ同じ）:

  | 都県 | 自治体数 | オープンデータ公開 | 商用利用不可 | 再配布・再利用不可 | 条件公開 |
  |---|---|---|---|---|---|
  | 埼玉 | 61 | 50 | 7（熊谷・本庄・春日部・上尾・日高・長瀞・上里） | 2（所沢・東松山） | 2（白岡・川島） |
  | 千葉 | 53 | 46 | 7（茂原・佐倉・浦安・南房総・香取・いすみ・横芝光） | 0 | 0 |
  | 東京 | 60 | 55 | 5（新宿区・調布・町田・あきる野・青ヶ島） | 0 | 0 |
  | 神奈川 | 31 | 30 | 1（湯河原町） | 0 | 0 |

  - 中学校区では、埼玉の春日部と上里も商用利用不可。
  - 文京区（デモの地域）と八王子市は、小学校区・中学校区のどちらも「オープンデータ公開」。
  - 「再配布・再利用不可」（所沢・東松山）は取り込まない。「条件公開」（白岡・川島）は「地図データは参考情報」とする条件つきなので、取り込まないのが安全。「商用利用不可」は作品が非商用なら使えるが、チームで判断する。
- 出典の書き方: 「「国土数値情報（小学校区データ）」（国土交通省）（当該ページのURL）を加工して作成」。中学校区も同じ形。

### 2.5 T25 駅別乗降客数 S12（国土交通省）

- 項目: 駅の線（原則として鉄道データ N02 の駅と同じ位置）、駅名、駅コード、グループコード、運営会社、路線名、鉄道区分、年度ごとの乗降客数（人/日）・データ有無・重複コード（2011年度は S12_006〜009、2024年度は S12_058〜061）。
- 都道府県の属性がないので、今の `stations.parquet`（N02 由来）と駅コードかグループコードでつないで 1都3県に絞る。
- JR東日本の無人駅は「データ無」。
- 利用条件: CC BY 4.0。国土交通省の 2024-07-05 の報道発表（https://www.mlit.go.jp/report/press/tochi_fudousan_kensetsugyo17_hh_000001_00036.html ）に「「駅別乗降客数」はすべてのデータについて商用利用が可能となり」とある。
- 出典の書き方: 「出典：「国土数値情報（駅別乗降客数データ）」（国土交通省）（https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-S12-2024.html ）（取得日）を加工して作成」。

### 2.6 T26 自治体のごみのデータ

- デジタル庁「自治体標準オープンデータセット」では、収集曜日の列（ゴミ収集日）は「ゴミ集積場所一覧」の側にだけあり、「ゴミの分別方法一覧」にはない。
- **デモの地域（`eval/fixtures` は文京区。ゴミ袋の手がかりは入っていない）**
  - 文京区は「ごみと資源の収集日」を町名・丁目ごとに公開している（可燃・不燃・資源・プラスチックの曜日。CC BY 4.0）。今の `collection_areas` に文京区の行はないので、「置き換え」ではなく「行を足す」形になる。
  - 文京区はごみ集積所一覧を公開していない。
- **知識表に今ある自治体**
  - `collection_areas` の八王子市（20地区）は、収集日程も地区別の町名一覧もオープンデータでは公開されていない（分別方法一覧はある）。置き換えられない。
  - `trash_bags`（多摩26市の袋の値段）に当たるオープンデータは見つからなかった。袋の色も、市ごとの PDF にしかない。
- 1都3県の「ゴミ集積所一覧」は、確かめた5件（品川区・杉並区・武蔵野市・港区・日野市）がどれも清掃工場や拠点回収場所で、家庭ごみの集積所の位置ではなかった。

## 3. 人に決めてほしいこと

1. **T23（バス停）**: 最新版はオープンデータなので、非商用の扱いを心配する必要はなくなった。進めてよいか。
2. **T24（学区）**: 子どもに関わる推定を入れるか。入れる場合、「商用利用不可」の自治体（1都3県で 20 前後）を含めるか、「オープンデータ公開」の自治体だけにするか。
3. **T22（法人番号）**: 取得を `fetch.sh` の自動取得にするか、ブラウザで取って `data-prep/raw/` に置くか。取り込む範囲（閉鎖を除く、会社だけ など）をどこまで絞るか。
4. **T26（ごみ）**: 八王子市の行は置き換えられない。文京区の収集日を新しい行として足すか、T26 をここで止めるか。
